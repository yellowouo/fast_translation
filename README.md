# Fast Translation — 现代化极速划词翻译工具

<div align="center">

**基于 Rust + Slint 开发的 Windows 10/11 现代化常驻后台划词翻译神器**

极速响应 · 内存轻量 · 双引擎切换（通用 / 大模型） · 无感取词 · 原生 TTS 发音

</div>

---

## 🌟 核心特性

- 🎯 **智能混合划词取词**：
  - **Windows UI Automation** 优先无感提取，不干扰剪贴板；
  - 智能拖拽释放降级模拟 `Ctrl+C` 取词（自动恢复原本剪贴板，绝不污染剪贴板历史）；
  - **防误触双重过滤**：通过 Windows API `WM_NCHITTEST` 过滤窗口标题栏、边框缩放、滚动条、任务栏或桌面拖拽；同时自动识别并拦截 VS Code / Visual Studio 的空选区整行复制标记。
- 🤖 **百度双翻译引擎支持（托盘一键无缝切换）**：
  - **通用文本翻译**：秒级极速响应，适合日常阅读与快速查词查句；
  - **大模型文本翻译**：由百度文心大语言模型（LLM）赋能，结合语境智能意译与润色，句式表达更加通顺自然。
- 🎨 **现代化美观 UI**：
  - 基于 **Slint 1.17.1** 声明式原生 UI，粉紫渐变视觉、丝滑微动效与毛玻璃阴影；
  - **屏幕边缘智能吸附**：弹窗自动计算当前显示器可用工作区（避开任务栏），在屏幕边缘取词时自动吸附对齐，杜绝内容出界与截断。
- 🔊 **Windows 现代 WinRT 语音朗读**：
  - 采用 Windows 10/11 原生 WinRT 现代合成引擎（`Windows.Media.SpeechSynthesis` + `MediaPlayer`）；
  - 自动识别中英文字符并匹配最优高质量系统音色。
- ⌨️ **全局快捷键与可视化设置**：
  - 随时随地按快捷键唤醒翻译（默认 `Alt+Q`）；
  - 内置可视化快捷键录入与设置面板，支持一键临时禁用/恢复所有快捷键。
- ⚡ **极致性能与低资源占用**：
  - 纯异步事件驱动架构（Tokio + MPSC），多级 LRU 本地缓存；
  - 内嵌 Windows 高清图标与 PE 资源元数据。

## 🛠️ 技术栈

| 模块 / 特性 | 实现技术 | 说明 |
| :--- | :--- | :--- |
| **开发语言** | **Rust** (Edition 2021) | 内存安全、零成本抽象、高性能 |
| **UI 框架** | **Slint 1.17.1** | 现代化声明式 GUI 框架，原生渲染 |
| **系统底层交互** | **windows-rs 0.58** | 官方 Windows API 绑定 |
| **鼠标全局监听** | **Win32 `WH_MOUSE_LL`** | 独立线程消息泵与低延迟鼠标钩子 |
| **智能文本提取** | **UI Automation + Win32 API** | `IUIAutomationTextPattern` + 模拟输入与格式检测 |
| **网络与翻译** | **Reqwest + Tokio + Rustls** | 异步非阻塞网络通信，支持 MD5 鉴权与 JSON 交互 |
| **翻译平台** | **百度翻译开放平台** | 通用翻译 API + 大模型文本翻译 API (`aiTextTranslate`) |
| **语音合成 (TTS)** | **Windows WinRT API** | `SpeechSynthesizer` 与 `MediaPlayer` 硬件加速流式播放 |
| **本地缓存** | **lru (Least Recently Used)** | 按模式分段的快速内存缓存 |
| **配置系统** | **TOML + Serde** | 强类型声明与自动化文件持久化 |
| **Windows 资源** | **winres 0.1** | PE 文件元数据与多尺寸 ICO 图标嵌入 |

## 🚀 快速上手

### 1. 前置环境准备

1. **Rust 编译环境**：安装官方 [Rustup](https://rustup.rs/)。
2. **C++ 编译工具链**：Windows 系统需安装 Visual Studio Build Tools（勾选 "C++ 桌面开发"）。

### 2. 编译与打包

```powershell
# 1. 克隆 / 进入项目目录
cd fast_translation

# 2. 调试编译与运行
cargo run

# 3. 生产环境优化打包（启用 LTO、代码剥离与体积优化）
cargo build --release
```
编译产物位于 `target/release/fast_translation.exe`。

## ⚙️ 百度翻译 API 申请与配置指南

本项目已接入百度翻译开放平台的**通用文本翻译**与**大模型文本翻译**，只需同一组凭证即可同时使用两项服务。

### 步骤 1：获取 APP ID 与 密钥 (Secret Key)

1. 打开并登录 [百度翻译开放平台](https://fanyi-api.baidu.com/)；
2. 完成开发者认证（个人认证即享每月免费额度）；
3. 进入 **[管理控制台]**，在页面下方即可查看您的 **APP ID** 和 **密钥 (Secret Key)**；
4. 在控制台的“产品服务”中，确认已开通 **通用文本翻译** 以及 **大模型文本翻译**。

---

### 步骤 2：配置 `config.toml`

程序首次运行时会自动在同级目录生成 `config.toml` 配置文件，您也可以直接手动创建或编辑：

```toml
[baidu]
# 必填：百度翻译开放平台申请的 APP ID
appid = "你的_APP_ID"

# 必填：百度翻译开放平台的 密钥 (Secret Key)
secret_key = "你的_SECRET_KEY"

# 可选：源语言与目标语言（auto 为自动识别，zh 为简体中文，en 为英文）
from = "auto"
to = "zh"

# 可选：翻译引擎模式（支持托盘菜单动态切换并自动保存）
#   "general" -> 百度通用文本翻译（极速响应）
#   "llm"     -> 百度大模型文本翻译（文心大模型深度翻译与润色）
mode = "general"

[app]
# 可选：本地 LRU 缓存条数上限（默认 512）
cache_size = 512

# 可选：划词后是否自动触发翻译流程（默认 true）
auto_translate = true

[hotkey]
# 可选：全局唤醒翻译快捷键（支持在右键托盘“设置”中可视化修改）
translate = "Alt+Q"

# 可选：全局启用/禁用程序快捷键（随时一键暂停/恢复划词翻译）
toggle = "Alt+M"

# 可选：是否启用全局快捷键
enabled = true

# 可选：是否开启拖拽划词降级模拟复制（默认 true）
drag_copy_fallback = true
```

## 💡 使用指南

1. **划词即翻**：
   在任意软件（VS Code、浏览器、Word、PDF 阅读器、终端等）中用鼠标选中文字，文字右侧会即时浮现粉色悬浮球。鼠标移动到悬浮球上方即可展开译文卡片。
2. **快捷键独立输入翻译**：
   按下快捷键 `Alt+Q`，立刻在光标旁唤醒独立的空白翻译输入框，直接键入或粘贴您想翻译的任意文本，即打即译。
3. **全局启用/禁用程序**：
   - 随时按下快捷键 `Alt+M`（或在右键托盘菜单中点击），即可一键在 **(运行中)** 和 **(禁用中)** 之间切换。
   - 禁用时，划词取词与翻译唤醒快捷键全面静默，托盘悬浮提示与菜单标题实时变更为 `(禁用中)`，防止游戏或全屏应用误触。
4. **右键托盘菜单切换引擎与设置**：
   右键任务栏右下角的系统托盘图标：
   - 顶部标题实时展示状态：`Fast Translation 划词翻译 (运行中)` / `(禁用中)`；
   - 点击 **⏸ 禁用程序 / ▶ 启用程序**：一键暂停或恢复取词；
   - 点击 **● 通用文本翻译**：切换为快速查词查句模式；
   - 点击 **● 大模型文本翻译**：切换为文心大模型润色与深度翻译模式；
   - 点击 **⚙ 快捷键设置...**：打开可视化设置面板自定义唤醒按键。
5. **语音发音**：
   点击译文卡片底部的 **🔊 发音** 按钮，系统将自动调用原生高清音色朗读内容。

```
└── config.toml         # 运行时配置文件
```
